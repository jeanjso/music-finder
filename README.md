# 🎵 music-finder

> Buscador de canciones con preview de audio. Construido con JavaScript vanilla y la iTunes Search API.

## ✨ Features (MVP)

- [ ] Búsqueda por nombre de canción o artista
- [ ] Resultados con artwork, canción, artista y álbum
- [ ] Reproducción de preview de 30 segundos
- [ ] Manejo de estados: loading, error, sin resultados
- [ ] Diseño responsive mobile-first

## 🛠️ Stack

- HTML5
- CSS3 (vanilla, mobile-first)
- JavaScript ES6+
- [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/)

## 🚀 Cómo correr localmente

```bash
git clone git@github.com:jeanjso/music-finder.git
cd music-finder
# Abre index.html con Live Server (extensión de VS Code)
```

## 📁 Estructura

```
music-finder/
├── index.html
├── css/
│   └── styles.css
└── js/
    ├── api.js       # Lógica de llamadas a iTunes API
    ├── ui.js        # Manipulación del DOM
    └── main.js      # Inicialización y coordinación
```
